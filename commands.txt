Solution: Bootstrap Host Qt Build

Qt provides a helper for building host Qt tools first:

Create a separate build folder for host Qt:

mkdir -p ~/qt6-host-build
cd ~/qt6-host-build

Configure host Qt build:

cmake ~/qnx800/qt6/qtbase \
  -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX=~/qt6-host
